# Endpoint and data-use notes

Reviewed 2026-10-27. This app calls only the documented, unauthenticated GET endpoints for published job listings:

- [Greenhouse Job Board API](https://docs.greenhouse.io/job-board.html): Greenhouse says Job Board data is public and GET endpoints need no authentication. Listing retrieval is `GET /v1/boards/{board_token}/jobs`; `content=true` adds the published description.
- [Lever Postings API support note](https://hire.lever.co/developer/support): Lever describes its Postings API as publicly accessible and intended for published postings. The documented public job-site feed used here is `GET https://api.lever.co/v0/postings/{site}?mode=json`.
- [Adzuna Search API](https://developer.adzuna.com/overview): Adzuna documents search by country using an app ID and key. Its current OpenAPI spec lists 19 country codes: GB, US, AT, AU, BE, BR, CA, CH, DE, ES, FR, IN, IT, MX, NL, NZ, PL, SG, and ZA. The API terms explicitly include personal job search as a permitted use, require registration, and say free access is intended for evaluation; higher-volume plans and limits are account-specific. Listings are linked through Adzuna's advertiser redirect URL.
- Direct career-page URLs are accepted only when they identify a Greenhouse or Lever public board; the URL is resolved locally to the documented board identifier before polling. The supplied NVIDIA URL is an Eightfold-powered career portal, not a Greenhouse or Lever board. NVIDIA's page indicates Eightfold; no documented public listing feed for this specific portal was identified, so the app rejects it instead of calling an undocumented internal endpoint. Use Adzuna's indexed NVIDIA listings for broader coverage, with its usual coverage and result-page limits.

The public endpoint documentation describes access and intended use for publishing a company's own job site; it is not an unambiguous license for arbitrary collection or redistribution. The vendors' general terms do not specifically grant this personal polling use. Before enabling a board, review that company's own careers-site terms and the current applicable vendor terms. Exclude any board whose terms or owner instructions disallow this use. This tool makes no POST calls, does not submit applications, and does not publish or host listings. Adzuna permits personal job search under its API terms, subject to key access, the current plan limits, and its requirement to send users to advertiser listings through the provided redirect URL.

Worldwide search covers only the countries and advertisements in Adzuna's index. It requests the newest 50 results for each role and country, so a broad query can have additional matches beyond that page. Some employers do not distribute listings to aggregators, and Adzuna's listing description is truncated. No public feed can guarantee every open role across every employer, ATS, and country. Add direct company boards to improve coverage for companies you care about.

Polling is sequential, defaults to a 1.5 second gap between company boards, sets a descriptive User-Agent, uses bounded timeouts, honors `Retry-After`, and retries only rate-limit/transient errors. Keep the company list modest. `request_delay_seconds` is configurable.

The SQLite database is private local state used to detect first sightings and calculate counts. It contains listing titles, locations, links, and Greenhouse/Lever descriptions used for matching. Keep `data/` out of version control. The GitHub Actions workflow refuses to run on a public repository because Actions cache contents can be visible to repository readers. Prefer the local systemd timer if private cache persistence is not acceptable. Telegram messages go only to the configured chat.
